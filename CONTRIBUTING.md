# Contributing

Thanks for your interest in improving this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Keep changes small and focused.
4. Update docs when behavior changes.
5. Open a pull request with a clear summary.

## Pull request checklist

- The change is scoped and easy to review.
- `README.md` is updated if setup or workflow changed.
- Modelfile changes are intentional and documented.
- No unrelated file churn is included.

## Style

- Prefer minimal, explicit changes.
- Keep examples copy-paste friendly.
- Avoid broad rewrites when a small diff is enough.

## Reporting issues

When filing an issue, include:

- OS and version
- Ollama version (`ollama --version`)
- Cline extension version
- Exact steps and command output
